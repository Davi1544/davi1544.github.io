# Strike-through Exploratory Analysis 

## Overview
This week, I conducted some exploratory experiments on a labeled set of text pixels that contains both pure strike-through and covered text pixels. My goal was to identify some criteria for separating them that we could eventually use to recover the lost text.

## Experiments

I started experimenting by designing a simple method to isolate pixels that could contain covered text. To achieve this, I used the fact that both types of text pixels are considerably darker than paper pixels. Furthermore, strike-through pixels are even darker, so a simple threshold on the grayscale conversion of the sample image was enough to create a mask where only strike-through pixels were selected.

![grayscale mask](/assets/img/posts/week13/grayscale-mask.png)

As you can see, the mask does contain some pixels that are not of interest, but, for the context of this analysis, these few pixels are not relevant. 

After selection of the strike-through pixels, I decided to first plot their variance over each channel. If the variance were small, it would indicate there might not be enough data to recover coverted undertext pixels from the set.

![variance channels](/assets/img/posts/week13/variance-channels.png)

The plot shows there is considerable variance across all channels, particularly 11, 13, 14 and 15 (starting from 0). We'll explore these channels further in the next experiments. This suggests that there is spectral variation within the strike-through pixels that may be useful for distinguishing pure strike-through from covered undertext.

Another possible way to explore this set is to apply dimensionality reduction on its pixels and plot them. If there are well-defined and separated clusters, they might reveal a way to distinguish covered undertext pixels.

The following images show the result of dimensionality reduction of the strike-through pixels for different algorithms.

![PCA reduction](/assets/img/posts/week13/pca-dim.png)

![ICA reduction](/assets/img/posts/week13/ica-dim.png)

![UMAP reduction](/assets/img/posts/week13/umap-dim.png)

Observe that both PCA and ICA arrived at essentially the same map: a dense and uniform cluster surrounded by a few isolated pixels. This is not a directly useful result because the only cluster in these maps shows no obvious separation and the isolated pixels around it are too few to be the covered undertext pixels.

In the case of UMAP, the results are more promising. The UMAP reduction resulted in two very large, separated clusters with little to no isolated pixels around them.

If we then paint each cluster a different color in the RGB image, this is the result:

![UMAP clusters on RGB](/assets/img/posts/week13/umap-clusters-on-rgb.png)

Unfortunately, the clusters are not easily interpretable and do not separate pure strike-through and covered undertext pixels correctly.

As a last experiment, I decided to manually label some pixels on the set: the ones I was confident contained some remnant of undertext and the ones I was confident did not. I managed to label around one thousand pixels, which certainly isn't enough to train a model, but is enough for this type of analysis.

This is the result of plotting the average intensity of each pixel class across all channels (I also included paper pixels for comparison and the variance of each class).

![classes](/assets/img/posts/week13/average-per-class.png)

As you can see, there is some level of separation between the both strike-through classes, especially around channels 11 and 13. Another important observation is that the variance of each class is not particularly high, which further supports the possibility of separation.
